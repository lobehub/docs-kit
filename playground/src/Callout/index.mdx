## Introduction

MDX in docs-kit has no `:::` admonition syntax. When a page needs a highlighted note, import a component and render it, the way the guide pages on this site import `Callout`. This page also sets the optional frontmatter fields `status: beta` and `since: 6.2.1`. They are not drawn on the page: `status` is stored as Pagefind metadata, and both appear in the page's agent markdown at [/skills/components/callout.md](/skills/components/callout.md).
