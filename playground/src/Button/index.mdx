## Props

| Property   | Description                 | Type                                 |
| ---------- | --------------------------- | ------------------------------------ |
| `htmlType` | Native button type          | `'button' \| 'reset' \| 'submit'`    |
| `rest`     | Remaining native attributes | `Omit<ButtonHTMLAttributes, 'type'>` |
| `variant`  | Visual weight               | `'default' \| 'primary' \| 'text'`   |
